# TeacherOS Mobile

Diese Mobile-App dient als native Hybrid-Wrapper um die TeacherOS-Webanwendung.

## Idee

- Browser-first Web-UI bleibt die fachliche Kernimplementierung
- Capacitor deckt iOS/Android-Features wie Push, Statusbar und native WebView ab
- keine zweite fachliche App-Implementierung parallel zum Webprodukt
